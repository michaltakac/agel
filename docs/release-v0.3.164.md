# v0.3.164

Native combat transfer retains the initial judge-log snapshot for the
final byte-for-byte check. The preceding live recipient completed the
one-rat encounter but exited when that check referenced a missing binding.

The OSRS reader joins fragments with a tail-recursive Agel loop. In a
1 GiB native guest, reading a 256-byte fixture in eight fragments went
from 11,086 evaluator steps to 7,889, with identical bytes and service
callbacks. The hosted wire suite also passed against the private server.
