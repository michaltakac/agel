# v0.3.139

The native benchmark scorer boots with the memory size recorded by the
paired task. This lets it evaluate scores on the same boot image even
when that image needs more memory than the desktop harness default.

A 1 GiB guest evaluated the retained Cook’s Assistant pair. It reported
both gameplay outcomes as incorrect, the adaptive policy as committed,
and 41,370 nanodollars in verified judge charges. The writer's dollar
cost remained unknown.
