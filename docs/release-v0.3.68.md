# v0.3.68 · Bracket candidate replay with fixed controls

The native service optimizer keeps the initial profile to calculate the
safe work bound. After text judgment it measures the same recorded input
with the fixed policy, the candidate, then the fixed policy again.
Activation requires exact bytes, bounded service gaps and work, fewer
service calls, and lower elapsed time than both adjacent controls.
If timing fails, the retry receives all three timings.

The RuneScape quest harness now traces outgoing dialogue actions even
when they carry no recorded packet bytes.
