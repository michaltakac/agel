# v0.3.160

Native paired runs can report a committed policy that served no live
packets. The scorer retains the optimization charges and reports
`committed-unused` alongside the task result. A transfer donor still
requires live use of the committed policy.

The melee harness retains a corroborating server save even if a failed
guest run met the XP target. The guest failure remains visible. This
recovered an older paired run in which the fixed account met the XP
targets but the guest timed out waiting for an encounter to complete.
