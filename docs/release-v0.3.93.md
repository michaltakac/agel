# v0.3.93

Native crafting records the server's starting and final account state. A
passing run consumes five adamantite bars, retains the hammer, and saves
one platebody and exactly 312.5 Smithing XP on the same normal account.

The paired runner accepts two staged crafting accounts and runs the fixed
and live adaptive arms in sequence with shared runtime artifacts and
sources. The scorer requires matching starting stock and Smithing XP,
verifies the guest report against both server snapshots, and emits Agel
benchmark input. This comparison requires two successful guest runs.
