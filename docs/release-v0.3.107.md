# v0.3.107

Run `python3 scripts/test-native-economy-pair.py --transfer DONOR` to
compare a retained one-rat policy against a fixed policy on distinct
fresh accounts. The runner pins donor evidence, guest executable, and
sources. The fixed seed shares the donor boot and kernel but starts
without its protected journal or filesystem history.

Transfer replays the original cases retained by the donor version.
Older donors use explicit compatibility cases. The transfer still
replays the recorded byte workload and verifies the donor judge ledger.
