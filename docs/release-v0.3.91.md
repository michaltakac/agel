# v0.3.91 · Prepare separate crafting accounts

The crafting fixture can prepare a named account with a hammer, five
adamantite bars, and level 88 Smithing, then revoke the setup privileges
before native play. Two dedicated accounts were prepared and verified at
normal rights.

The native harness accepts the selected fixture and allows
`--craft --optimize --live`. It measures from the same task boundary
for fixed and adaptive runs and includes optimization time in the
adaptive run. New successful runs verify the resulting platebody,
consumed bars, retained hammer, and observed XP against the server save.
The first fixed and adaptive trials are underway.

These trials stage the raw bars. Full crafting from gathered materials
and a matched crafting score remain open.
