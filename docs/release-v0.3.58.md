# v0.3.58 · Score measured melee failures

When the native melee task raises a condition, Agel records the elapsed
task time and the runner reads back the account from the private server.
The paired scorer can retain the arm as incorrect if the saved account
corroborates incomplete training and the other comparison checks pass.
Adaptive failures still require matching judge receipts on the guest disk.

A regression combined the earlier failed arm's disk, ledger and saved
account with a fixture clock. The scorer retained the incorrect outcome
and both judge charges and rejected an XP snapshot older than the guest
observations. The earlier run lacked a task clock of its own.
