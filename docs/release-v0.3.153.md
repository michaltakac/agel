# v0.3.153

An Agel agent can replay the recorded cases for a retained tool version
through its mailbox. The replay returns a receipt and leaves the active
version and call history intact. Activation and revert still use the
judge and replay gate.

The retained macro-built version and the active reverted version each
passed both recorded cases in hosted Agel and in a native Agel guest
with 1 GiB of RAM.

The legacy DOOM launcher selects the standard graphics kernel and
installs the demo as example files. The kernel has a single graphics
feature for both launches.
