# v0.3.79 · Add an adaptive native economy arm

`python3 scripts/test-native-network.py --economy` runs the fixed arm.
`python3 scripts/test-native-network.py --economy --optimize --live`
lets Agel propose, judge, and replay a byte-service policy before the
same first-sale task. Both start with the same encoder, game adapter,
guest memory, and account setup. If the gate refuses the proposals,
the adaptive run continues with the fixed encoder.

Agel measures from the same task boundary in both arms. The adaptive
elapsed time includes the optimization attempt. The guest marks its
adaptive billing incomplete and preserves unknown cost. The harness
retains writer usage and the protected judge receipts for reconciliation.

The first paired executions are underway. This workload measures one
bronze-bar sale on the private server.
