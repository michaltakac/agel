# v0.3.92

The legacy DOOM engine, Agel port, and WAD diagnostic live with the Agel
agents in `examples/doom`. The C program builder accepts a source directory
and continues to use `boot/posix/c` by default. The legacy launch and test
scripts pass the example directory explicitly.

RuneScape protocol and gameplay code live under `examples/osrs`. The
optional legacy DOOM kernel feature still carries desktop launch and
handover hooks.
