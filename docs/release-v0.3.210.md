# v0.3.210

Native melee scores now include the XP goal and the server-saved
Attack, Strength, Defence, Hitpoints, and stance for both arms. XP
values are reported in tenths. A failed run retains its failure verdict
and shows how far it got.

The native score runner waits for the complete guest exit line before
reading its status. A 1 GiB guest evaluated a retained pair and
reported the different progress of both failed arms.
