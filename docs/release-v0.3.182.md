# v0.3.182

The native pair scorer accepts `--writer-rates INPUT CACHED OUTPUT` in
nanodollars per token. Agel OS evaluates the estimates from retained
usage receipts, including donor learning when a donor is supplied.
The estimates appear separately from the original costs and verdict.

The retained crafting pair produced an estimate inside Agel OS with
synthetic rates. Its actual cost verdict remained unknown. Scoring
without the option produced the same input as before.
