# v0.3.202

The native melee scorer verifies when adaptation happened. The trace
must show Attack reaching its XP goal before the optimizer starts.
If the next phase begins, the optimizer must already have returned.
Provider dispatches outside that interval invalidate the comparison.

A measured failure before the transition can be scored at zero model
cost when the guest trace and protected judge journal show zero calls.
Failures inside optimization retain their separate trace marker and
the task's single elapsed-time measurement.

Trace fixtures accepted valid phase order and rejected early and late
dispatches, duplicate transitions, and insufficient Attack XP.
